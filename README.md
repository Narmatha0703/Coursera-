# Coursera

🎓 Coursera Clone – HTML & CSS

       A clean, responsive Coursera-style homepage clone built using only HTML and CSS. This project replicates the look and feel of the Coursera website's front-end, focusing 
       on layout, structure, and styling without any JavaScript.

🚀 Features

       Fully responsive layout

       Modern, clean UI inspired by Coursera

       Pure HTML5 and CSS3 – no frameworks or JavaScript

       Semantic and accessible markup

       Organized code structure for easy maintenance


🛠️ Built With

        HTML5

        CSS3 (Flexbox & Grid)
